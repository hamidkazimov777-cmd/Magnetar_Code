## Установка

```bash
npm i -g magnetar-code
magnetar provider
magnetar
```

Без установки — `npx magnetar-code`. Нужен Node.js 20.11+.

## Что это

`magnetar` — агент в терминале: читает и правит файлы, запускает команды, ищет
по репозиторию и ведёт план работ. Каждая запись в файл и каждая команда
показываются на подтверждение; команды только для чтения (`git status`, `ls`)
не дёргают. `y` — разрешить, `a` — больше не спрашивать про это в этом проекте.

`magnetar web` открывает монитор в браузере: тот же контекст и те же сессии,
живой поток агента, diff каждой правки, дерево файлов с пометкой изменённых,
план и память проекта. Запросы к модели идут из Node — ключ в браузер не
попадает никогда.

## Настройка провайдера (BYOK)

```bash
magnetar provider
```

Выбираешь пресет (OpenRouter, TokenRouter, Kimi, OpenAI, DeepSeek, Together,
LM Studio, Ollama) — остаётся ввести только API-ключ. Список моделей
подтягивается с эндпоинта. Ключ уходит в системный keychain, не в конфиг.

## Неинтерактивный режим

```bash
magnetar -p "какие роуты есть в этом приложении?"
cat error.log | magnetar -p "почему падает"
magnetar -p "добавь health check" --permission-mode auto-edit --output-format json
```

`--output-format json` печатает ответ, id сессии, число шагов, токены и
стоимость одним объектом — для скриптов и CI.

## Память проекта

`MAGNETAR.md` в корне репозитория попадает в каждый системный промпт: команды
сборки, соглашения, грабли. `/init` пишет первый вариант, `/memory` показывает
все слои. Отдельные факты живут в `.magnetar/memory/` по файлу на факт — их
видно в диффе и можно коммитить.

## Структура репозитория

| Пакет           | npm                         | Что это                                                    |
| --------------- | --------------------------- | ---------------------------------------------------------- |
| `packages/core` | `@magnetar/core` (internal) | Провайдеры, agent loop, инструменты, сессии, память, демон |
| `packages/cli`  | `magnetar-code`             | TUI на Ink и неинтерактивный режим                         |
| `packages/web`  | `@magnetar/web` (internal)  | Монитор; собирается в бандл внутри CLI                     |

## Разработка

```bash
npm install     # из корня, npm workspaces
npm run check   # format + lint + typecheck + test
npm run build   # монитор, затем CLI с монитором внутри
npm run cli     # запустить CLI из исходников
```

CI гоняет проверки и сборку на Node 20, 22 и 24.

## Безопасность

Агент выполняет команды и правит файлы. По умолчанию каждое такое действие
требует подтверждения; пути ограничены папкой проекта; ключи лежат в keychain;
демон слушает только loopback и требует токен. Подробности и модель угроз —
[`SECURITY.md`](SECURITY.md).
